
# Assignment 01 - Basic HTML

## Overview

This assignment serves as an introduction to fundamental HTML concepts and webpage structure. The objective was to understand how HTML elements are used to create and organize content on a web page.

The webpage demonstrates the use of headings, paragraphs, text formatting, hyperlinks, unordered lists, and nested lists to build a simple yet structured HTML document.

## Concepts Learned

### 1. Paragraph Tag

Used to display blocks of text.

```html
<p>Your content goes here</p>
```

Example:

```html
<p>This is my first paragraph.</p>
```

---

### 2. Heading Tag

Used to create headings of different sizes.

```html
<h1>Main Heading</h1>
```

Example:

```html
<h1>Web Pages Are Exciting Too</h1>
```

Common heading levels:

```html
<h1></h1>
<h2></h2>
<h3></h3>
<h4></h4>
<h5></h5>
<h6></h6>
```

---

### 3. Bold Tag

Used to make text bold.

```html
<b>Bold Text</b>
```

Example:

```html
<b>paragraph</b>
```

---

### 4. Hyperlink Tag

Used to navigate to another webpage.

```html
<a href="https://www.google.com">Go to Google</a>
```

Example:

```html
<a href="https://www.google.com">Link to Google</a>
```

---

### 5. Unordered List

Used when the order of items is not important.

```html
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>
```

Example:

```html
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>
</ul>
```

---

### 6. List Item Tag

Represents a single item inside a list.

```html
<li>Item Name</li>
```

Example:

```html
<li>Apple</li>
```

---

### 7. Nested Unordered List

Used to create subcategories within a list.

```html
<ul>
    <li>Fruits
        <ul>
            <li>Apple</li>
            <li>Mango</li>
        </ul>
    </li>
</ul>
```

Example:

```html
Fruits
 ├── Apple
 ├── Banana
 └── Mango
```
