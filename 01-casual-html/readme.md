The project includes headings, paragraphs, horizontal rules, hyperlinks, image hyperlinks, emojis, comments, unordered lists, and nested lists.

# Concepts Learned

## 1. Heading Tags

Used to define headings and titles.

### Syntax

```html
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Section Heading</h3>
```

### Example

```html
<h1>Full stack web technologies 😊😅</h1>
```

---

## 2. Paragraph Tag

Used to display blocks of text.

### Syntax

```html
<p>Your content goes here.</p>
```

### Example

```html
<p>Lorem ipsum dolor sit amet...</p>
```

---

## 3. Horizontal Rule

Used to separate sections with a horizontal line.

### Syntax

```html
<hr>
```

---

## 4. Unordered List

Used when the order of items is not important.

### Syntax

```html
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>
```

### Example

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

---

## 5. List Item Tag

Represents an individual item inside a list.

### Syntax

```html
<li>Item Name</li>
```

### Example

```html
<li>React</li>
```

---

## 6. Nested Lists

Used to create categories and subcategories.

### Syntax

```html
<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>
```

---

## 7. Hyperlinks

Used to navigate to another webpage.

### Syntax

```html
<a href="URL">Link Text</a>
```

### Example

```html
<a href="https://www.google.com">
    Ref-1
</a>
```

---

## 8. Opening Links in a New Tab

### Syntax

```html
<a href="URL" target="_blank">
    Link Text
</a>
```

---

## 9. Image Hyperlinks

Used to make images clickable.

### Syntax

```html
<a href="URL">
    <img src="IMAGE_URL" alt="Image">
</a>
```

### Example

```html
<a href="https://www.google.com" target="_blank">
    <img src="https://upload.wikimedia.org/wikipedia/commons/2/2f/Google_2015_logo.svg"
         alt="Google"
         width="120">
</a>
```

---

## 10. HTML Comments

Comments are ignored by the browser and help organize code.

### Syntax

```html
<!-- This is a comment -->
```

### Example

```html
<!-- frontend -->
<!-- backend -->
<!-- database -->
```

---

## 11. Emojis

Emojis can be directly used inside HTML content.

### Example

```html
<h1>Full stack web technologies 😊😅</h1>
```
