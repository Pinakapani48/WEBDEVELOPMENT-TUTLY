# Concepts Learned

## 1. Inline CSS

CSS is applied directly inside an HTML tag.

### Syntax

```html
<h1 style="color:red;">Hello World</h1>
```

---

## 2. Internal CSS

CSS is written inside the `<style>` tag in the `<head>` section.

### Syntax

```html
<style>
h1{
    color: blue;
}
</style>
```

---

## 3. External CSS

CSS is written in a separate `.css` file and linked with HTML.

### HTML

```html
<link rel="stylesheet" href="styles.css">
```

### CSS

```css
h1{
    color: green;
}
```

# CSS Properties

## Color

Changes the text color.

### Syntax

```css
color: red;
```

---

## Text Align

Aligns text horizontally.

### Syntax

```css
text-align: center;
```

Possible values:

* left
* center
* right
* justify

---

## Text Decoration

Adds or removes decorations from text.

### Syntax

```css
text-decoration: underline;
```

Possible values:

* underline
* overline
* line-through
* none

---

## Text Transform

Controls capitalization.

### Syntax

```css
text-transform: uppercase;
```

Possible values:

* uppercase
* lowercase
* capitalize

---

## Text Shadow

Adds a shadow effect to text.

### Syntax

```css
text-shadow: 2px 2px 5px gray;
```

---

## Line Height

Controls the spacing between lines.

### Syntax

```css
line-height: 2;
```

---

## Letter Spacing

Controls spacing between characters.

### Syntax

```css
letter-spacing: 5px;
```

---

## Word Spacing

Controls spacing between words.

### Syntax

```css
word-spacing: 15px;
```

---

## Font Size

Changes the size of text.

### Syntax

```css
font-size: 28px;
```

---

## Font Family

Specifies the font type.

### Syntax

```css
font-family: Arial, sans-serif;
```

---

## Font Style

Controls the style of text.

### Syntax

```css
font-style: italic;
```

Possible values:

* normal
* italic

---

## Font Weight

Controls the thickness of text.

### Syntax

```css
font-weight: bold;
```

Possible values:

* normal
* bold
* 100–900
