# Concepts Learned

## 1. Internal Hyperlinks

Used to navigate to different sections within the webpage.

### Syntax

```html
<a href="#html">HTML</a>
```

---

## 2. ID Attribute

Used as a destination for internal hyperlinks.

### Syntax

```html
<div class="html" id="html">
```

---

## 3. Background Color

Used to style sections.

### Syntax

```css
background-color: skyblue;
```

---

## 4. Text Color

Used to change text color.

### Syntax

```css
color: aliceblue;
```

---

## 5. Text Alignment

Used to center content.

### Syntax

```css
text-align: center;
```

---

## 6. Padding

Used to create spacing inside elements.

### Syntax

```css
padding: 80px;

padding: 100px;
```

---

## 7. Margin

Used to create spacing outside elements.

### Syntax

```css
margin-top: 50px;

margin-top: 700px;
```

---

## 8. Font Size

Used to control text size.

### Syntax

```css
font-size: 1.5rem;

font-size: 2rem;
```

---

## 9. Pseudo-Class :hover

Used to apply styles when the mouse pointer is placed over an element.

### Syntax

```css
a:hover{
    color: aliceblue;
    background-color: rgb(42, 82, 42);
    padding: 2px 10px;
}
```

### Purpose

Provides visual feedback and improves user interaction.

---

## 10. Universal Selector

Applies styles to all elements.

### Syntax

```css
*{
    padding: 0;
    margin: 0;
    box-sizing: border-box;
}
```

---

## 11. Box Sizing

Ensures padding and borders are included within the total size of elements.

### Syntax

```css
box-sizing: border-box;
```
