
# 02.2 - Poster Project

## Overview

This project recreates a poster-style webpage using HTML and CSS. The webpage consists of an image, a title, and descriptive text arranged to resemble a motivational poster. Styling is applied using an external CSS file to create an attractive and visually appealing design.

# Concepts Learned

## 1. Image

Used to display the poster image.

### Syntax

```html
<img src="./poster.jpg" alt="Poster image">
```

---

## 2. Heading

Used to display the title of the poster.

### Syntax

```html
<h1>Poster Title</h1>
```

---

## 3. Paragraph

Used to display the description or quote.

### Syntax

```html
<p>Poster description goes here.</p>
```

---

## 4. External CSS

Used to apply styling from a separate CSS file.

### Syntax

```html
<link rel="stylesheet" href="./styles.css">
```

---

## 5. Background Color

Used to define the background color of the webpage.

### Syntax

```css
body{
    background-color: black;
}
```

---

## 6. Text Color

Used to style the text.

### Syntax

```css
color: white;
```

---

## 7. Text Alignment

Used to center the contents.

### Syntax

```css
text-align: center;
```

---

## 8. Font Family

Used to customize the appearance of text.

### Syntax

```css
font-family: serif;
```

---

## 9. Font Size

Used to control the size of text.

### Syntax

```css
font-size: 2rem;
```

---

## 10. Margin

Used to create spacing around elements.

### Syntax

```css
margin-top: 50px;
margin: auto;
```

---

## 11. Width

Used to control the width of elements.

### Syntax

```css
width: 50%;
```

---

## 12. Box Sizing

Ensures padding and borders are included within the total size of elements.

### Syntax

```css
box-sizing: border-box;
```
