
# Day 04 - Black Goose Bistro Webpage

## Overview

This project recreates the **Black Goose Bistro** webpage using HTML and CSS. The webpage contains a logo section followed by information about the restaurant, catering services, and location and hours. Styling is applied using an external CSS file to create a clean and visually appealing layout.

# Concepts Learned

## 1. Image

Used to display the Black Goose Bistro logo.

### Syntax

```html
<img src="image-url" alt="image not available">
```

---

## 2. Headings

Used to display titles and section names.

### Syntax

```html
<h1>BLACK GOOSE BISTRO</h1>

<h2>The Restaurant</h2>
```

---

## 3. Paragraph

Used to display textual content.

### Syntax

```html
<p>
    The Black Goose Bistro offers casual lunch and dinner fare in a hip atmosphere.
</p>
```

---

## 4. Italic Text

Used to emphasize text.

### Syntax

```html
<i>We'll handle the cooking.</i>
```

---

## 5. Horizontal Rule

Used to separate sections of the webpage.

### Syntax

```html
<hr>
```

---

## 6. Div

Used to organize different sections of the webpage.

### Syntax

```html
<div class="mainlogo">

<div class="para1">

<div class="para2">

<div class="para3">
```

---

## 7. External CSS

Used to apply styling from a separate CSS file.

### Syntax

```html
<link rel="stylesheet" href="./styles.css">
```

---

## 8. Universal Selector

Applied to all elements.

### Syntax

```css
*{
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

---

## 9. Background Color

Used to set the background color of the webpage.

### Syntax

```css
body{
    background-color: blanchedalmond;
}
```

---

## 10. Text Alignment

Used to center content.

### Syntax

```css
text-align: center;
```

---

## 11. Padding

Used to create spacing inside elements.

### Syntax

```css
padding-top: 50px;
```

---

## 12. Margin

Used to create spacing outside elements.

### Syntax

```css
margin-top: 30px;
margin-bottom: 30px;
margin-left: 200px;
```

---

## 13. Width and Height

Used to define dimensions of elements.

### Syntax

```css
width: 80%;
height: 2px;
```

---

## 14. Colors

Used to style text and elements.

### Syntax

```css
color: brown;
background-color: skyblue;
background-color: blanchedalmond;
```

---

## 15. Box Sizing

Ensures padding and borders are included within the total size of elements.

### Syntax

```css
box-sizing: border-box;
```
